The Graveyard

Ideas that didn't make it. The lessons remain.

  • Concurseiro Zen: Mentorship for exams. Lesson: Don't teach what you're tired of learning about.
  • Political Data Analysis Course: Python for political science. Lesson: Impostor syndrome killed it before the market could.
  • Parecer Detector: Internal legislative tool. Lesson: Useful tools don't spread themselves.
  • Mindflip App: Meditation app. Lesson: Coding for yourself is fun; selling to others is a different job.
  • Wisebots: No-code chatbots. Lesson: "Build it and they will come" is a lie. Also, bubble.io lock-in hurts.
  • Pieter Coach: AI clone of Pieter Levels. Lesson: Don't build things that make you feel like a sycophant.
  • IndieAI Directory: AI tools directory. Lesson: Manual data entry is hell. Don't compete on commodities.
  • IndieAI Newsletter: Weekly AI updates. Lesson: The "content treadmill" leads to burnout if you don't love the topic.
  • Conversa-AI: Customer support SaaS. Lesson: No founder-product fit. Maintaining a B2B SaaS is a grind I didn't want.
Most of these started as "I wonder if I could..."
Some turned into something. Most didn't. That's the point.

Cemitério de Projetos

Ideias que não vingaram. As lições ficaram.

  • Concurseiro Zen: Mentoria para concursos. Lição: Não ensine aquilo que você cansou de aprender.
  • Curso de Análise de Dados Políticos: Python para ciência política. Lição: A síndrome do impostor matou o projeto antes do mercado.
  • Parecer Detector: Ferramenta legislativa interna. Lição: Ferramentas úteis não se vendem sozinhas.
  • Mindflip App: App de meditação. Lição: Programar pra si mesmo é divertido; vender pros outros é outro trabalho.
  • Wisebots: Chatbots no-code. Lição: "Construa e eles virão" é mentira. E lock-in de plataforma (Bubble) dói.
  • Pieter Coach: Clone de IA do Pieter Levels. Lição: Não crie coisas que fazem você se sentir um puxa-saco.
  • IndieAI Directory: Diretório de ferramentas de IA. Lição: Entrada manual de dados é um inferno. Não compita por commodities.
  • IndieAI Newsletter: Atualizações semanais de IA. Lição: A "esteira de conteúdo" leva ao burnout se você não ama o tópico.
  • Conversa-AI: SaaS de suporte ao cliente. Lição: Sem founder-product fit. Manter um SaaS B2B é uma rotina que eu não queria.
A maioria desses começou como "será que eu consigo..."
Alguns viraram algo. A maioria não. Esse é o ponto.
