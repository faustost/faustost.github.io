# Personal Website - Fausto Sá Teles

This directory contains the specifications, design philosophy, and core content for Fausto Sá Teles' personal website. It serves as the blueprint for building a minimalist, content-focused site that reflects his "ZenTech" philosophy.

## Project Overview

*   **Goal:** Create a personal website to present Fausto's work, background, and projects.
*   **Philosophy:** "ZenTech" - bridging technology and mindfulness. The site embodies a "Beginner's Mind" (Shoshin) approach: humble, curious, and experimental.
*   **Strategy:** "Barbell Strategy" - combining public service stability with entrepreneurial experimentation.

## Directory Structure

*   **`spec.md`**: The technical and content specification. **This is the primary roadmap.** It defines the site structure, pages, technical stack, and immediate to-dos.
*   **`core.md`**: The philosophical foundation. It details the mission, target audience, tone of voice, and long-term strategy (micro-products, content flywheel). Read this to understand the *why* and *how* to write content for Fausto.
*   **`linkedIn.md`**: Draft content for social media profiles (LinkedIn), aligning with the site's bio.
*   **`images/`**: Contains visual assets like icons.

## Technical Specification (from `spec.md`)

*   **Stack:** Pure HTML + CSS (No build step). Minimal JS (only for language toggle).
*   **Hosting:** GitHub Pages.
*   **Design:** Minimalist, monochrome (black & white), text-heavy, generous whitespace.
*   **Pages:**
    1.  **Home (`index.html`):** Introduction and philosophy.
    2.  **Academic/Professional (`academic.html`):** Context, not just credentials.
    3.  **Projects (`projects.html`):** Experiments and tools ("Building small things").
    4.  **Contact (`contact.html`):** Channels to connect.
*   **Languages:** Portuguese (PT) and English (EN) via toggle.

## Core Mandates & Tone

When generating content or code for this project, strictly adhere to these principles defined in `core.md`:

*   **Tone:** Humble, curious, experimental. Avoid "Guru" or "Expert" language.
*   **Headline:** "Building small things. Asking big questions."
*   **Key Concept:** "How do we expand human agency in a time of rapid technological change?"
